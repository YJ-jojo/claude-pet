# Claude 宠物 · 使用说明

## 第一次运行

1. 从 GitHub 发布页下载 `ClaudePet-版本号-windows.zip`，解压到一个固定的文件夹（比如 `文档\ClaudePet`，以后自动更新会直接换这个文件夹里的程序），双击 `ClaudePet.exe`。`WebView2Loader.dll` 要和 exe 放在一起。
   - Windows 可能弹"已保护你的电脑"：点"更多信息 → 仍要运行"（自己编译的程序没签名，都会这样）。
2. 宠物自己看屏幕、讲解、翻译、帮你点，要靠 Claude Code（走你的 Max 额度，不另外花 API 的钱）。不用开终端：
   - 第一次打开时，如果电脑上还没有 Claude Code，宠物会用气泡提醒。托盘图标右键 → 设置，点 **一键安装**，它在后台跑官方安装脚本，装到 `%USERPROFILE%\.local\bin\claude.exe`。
   - 装好后点 **登录**，会打开浏览器，用你的 Max 账号点授权。网页最后如果给了一串授权码，粘到设置页的输入框里点确定。
3. 和 Claude 桌面版联动：设置 → **接入 Claude 桌面版**，然后把桌面版完全退出（右下角托盘图标右键 → 退出）再打开。
   - 之后在桌面版的任何聊天里（普通聊天、Code 标签页都行）都可以说"让宠物看看我的屏幕""让宠物指一下设置在哪""让宠物帮我点保存"。Claude 会用宠物的工具：`pet_say` 说话、`pet_look` 看窗口、`pet_point` 指按钮、`pet_act` 点击和打字、`pet_windows` 列窗口。第一次用时桌面版会问你允不允许，可以选"总是允许"。
   - 宠物"看"的是你最近在用的那个窗口（会跳过 Claude 桌面版自己），也可以说清楚看哪个窗口。
4. **安装提醒**：Code 标签页或终端里的 Claude Code 要你确认、停下来等你、问你问题时，宠物会"叮"一声并说出来。普通聊天没有对外的提醒接口，宠物收不到那边弹的确认框。

## 怎么用

| 想做什么 | 怎么做 |
|---|---|
| 看一眼当前窗口并讲给你听 | 点宠物的眼睛，或 `Ctrl+Alt+E` |
| 呼吸模式（后台一直盯着，有变化就讲） | 右键 → 开启呼吸模式，或 `Ctrl+Alt+B`。右键菜单里可选 安静 / 正常 / 细讲 |
| 指定它看哪个窗口 | `Ctrl+Alt+W`（被别的程序占了时自动变成 `Ctrl+Alt+Shift+W`）= 盯着你刚才用的窗口；或者把宠物拖到那个窗口上；或者对话框 → 观察 里勾选（可以勾好几个） |
| 让它帮你点、帮你输入 | 对话框里选"帮我操作"，说"点保存""在搜索框里输入天气"。不能撤销的操作它会先问你 |
| 让它指给你看在哪 | 对话框里选"指给我看"，它跑过去指着按钮，等你自己点 |
| 框选翻译 | `Ctrl+Alt+T`，拖一个框，出中英对照（外文翻中文，中文翻英文） |
| 打开对话框 | `Ctrl+Alt+空格`（被占了时自动变成 `Ctrl+Alt+Shift+空格`），或双击宠物 |
| 让它闭嘴、停手 | `Ctrl+Alt+Q`，或说话时点它一下 |
| 换音色、语速、大小、快捷键 | 右键 → 设置 |

快捷键都能在设置里改。

## 自动更新

- 宠物启动 30 秒后去 GitHub（YJ-jojo/claude-pet）查一次新版本，之后每 3 小时查一次；托盘图标右键 → **检查更新** 可以马上查。
- 有新版本时它自己下载、换掉程序、重启，宠物会说一声。正在帮你操作或正在说话时会等它忙完。
- 只装签名对得上的版本，别人改不了你装的程序。第一次要设置一次钥匙：
  1. 托盘图标右键 → **生成更新钥匙**。钥匙会复制到剪贴板，并打开 GitHub 仓库的 Secrets 页面。
  2. Name 填 `UPDATE_SIGNING_KEY`，Secret 里粘贴，点 **Add secret**。
  3. 两分钟后剪贴板会自动清掉。钥匙只在你的电脑（公钥）和 GitHub 的 Secrets（私钥）里。
- 没设置钥匙时不会自动更新。换电脑或重新生成钥匙后，要把新钥匙重新粘到 GitHub。
- GitHub 下载不动时，会自动换镜像（ghfast.top、gh-proxy.com）再试。镜像在 `config.json` 的 `update_sources` 里，可以自己改；镜像给的文件一样要过签名检查，改不了内容。下载进度和失败原因都记在 pet.log 里。

## 隐私

- 读屏、截图、文字识别都在你电脑上做。只有你让它看、或者呼吸模式开着时，才把"变了哪些字"（必要时一张截图）交给你的 Claude Code。
- 截图、录屏、共享屏幕时默认不拍进宠物（设置里可以关）。
- "不看名单"里的程序（默认有密码管理器、银行、支付宝）它永远不看、不碰。可以在 对话框 → 观察 里加。
- 设置和日志在 `%APPDATA%\com.claudepet.app\`。

## 出问题时

- 设置页最上面能看到 Claude Code 装了没有、登录没有，桌面版接上没有，提醒装了没有。安装、登录的过程在"安装 / 登录记录"里。
- 把日志发给我：按 Win+R，粘贴 `%APPDATA%\com.claudepet.app\logs` 回车，里面的 `pet.log`。（宠物开着时也可以：设置 → 其它 → 打开日志文件夹。）
- 日志里记了：启动每一步花了多久、是谁启动的宠物、崩溃的原因和位置、页面报错，以及每 30 秒一行的占用（宠物和网页进程的 CPU、内存，界面有没有卡住，画面帧率，视频掉帧）。不记你屏幕上的内容。
- 声音默认用微软在线音色（好听、快）；没网时自动换成 Windows 自带的。

## 换形象

人物素材做好后放进形象包文件夹就能用，格式见《形象包格式.md》。形象包放在 `%APPDATA%\com.claudepet.app\sprites\形象包名字\`，或者程序旁边的 `sprites\形象包名字\`。GitHub 上的发布不带人物形象包（人物有版权），只带一个简单的占位形象。两处都有同名形象包时，用 pack.json 较新的那份。默认用"叶瞬光"形象包，找不到时用占位形象；设置 → 宠物 → 形象包 可以切换。

## 0.3.4 改了什么

- 设置和聊天回到宠物自己的窗口（托盘 → 设置 / 对话，或双击宠物），不再用浏览器打开。窗口第一次打开时才建，不拖慢宠物启动；点关闭只是藏起来，再打开是瞬间的。
- 没装或没登录 Claude Code 时，宠物只用气泡提醒，不再自动弹出设置页。
- 之前启动慢、宠物出不来，查明主要是电脑内存被占满（长时间没重启）：同一台电脑重启后，宠物 1.3 秒就出来。觉得整机变卡时重启一次。

## 0.3.1 改了什么

- **修卡死**：程序只建宠物这一个窗口。0.3.0 在你电脑上建另外三个窗口（指示圈、框选翻译、对话框）时，每个要 8–20 秒，有一次一直建不出来；建的时候整个程序卡住，宠物点不动、拖不动，设置打不开。
- 对话框（聊天、观察、设置）改在浏览器里打开：托盘右键 → 打开对话框 / 设置，或双击宠物。网址只有本机能打开，带每次启动随机生成的口令；宠物重启后旧页面会提示失效，从托盘重新打开就行。
- 按钮上的指示圈、框选翻译改成画在宠物窗口里（用到时宠物窗口临时变大）。
- `%APPDATA%` 和程序旁边都有同名形象包时，用 pack.json 较新的那份（以前总是用 `%APPDATA%` 那份，旧包会挡住新包）。
- 自动更新下载时把进度、速度和失败原因（断在多少、等了多久）记进 pet.log；GitHub 下载不动时换镜像再试。
- 形象包可以在 pack.json 里用 `idle` 定待机小动作的间隔和范围，比如每 30–60 秒才眨一次眼（见《形象包格式.md》）。
- 待机小动作等待机循环回到开头才切进去，姿势接得上；间隔从小动作播完算起。

## 0.3.0 改了什么

- 代码放到了 GitHub（YJ-jojo/claude-pet），新版本由 GitHub 自动编译发布。
- 自动更新：自己查、自己下载、自己换程序重启，只装签名对得上的版本（见"自动更新"）。
- 内置的占位形象换成了一个简单的黄色小圆球；GitHub 上不放有版权的人物图。

## 0.2.2 改了什么

- 修"宠物透明"：0.2.1 用显卡把透明视频画到画面上，在你的电脑上画出来整片透明。现在改在内存里画（同一份视频这样画在你电脑上是正常的，日志里量身体范围那一步证明了）。还是透明的话，程序会自动改成直接显示视频，并把结果写进日志。
- 启动不再等 4 个窗口全建好：托盘、快捷键、本地服务（Claude 桌面版靠它连宠物）先起来，宠物窗口第一个建，其余三个在后台建。0.2.1 在你电脑上 4 个窗口一个接一个建了 117 秒，这期间这些都用不了。
- 启动没完成时，每 5 秒往日志写一行卡在哪一步、网页进程有几个。
- 快捷键被别的程序占了（你电脑上 `Ctrl+Alt+W` 和 `Ctrl+Alt+空格` 都被占了）时，自动加上 Shift 再注册，并写进设置；右键菜单里显示的是实际生效的快捷键。
- 视频没出新的一帧就不重画，144Hz 显示器上省一半以上的转换。

## 0.2.1 改了什么

- 修了"有时打不开"的一个原因：宠物窗口建出来时是隐藏的，0.2.0 要等页面的动画帧才把它摆好、显示出来，可隐藏的页面拿不到动画帧，于是有时一直不出来（在 Linux 上实测复现过，修好后 1 秒内出来）。另外启动 10 秒还没出来的话，程序会强制显示。
- 加了详细日志（见"出问题时"）。
- 带上叶瞬光形象包并默认使用。
- 在桌面版里让宠物点按钮，可以直接说按钮上的字，少一次来回。
- 呼吸模式看到画面变了，宠物先做个"看过去"的动作；说话前先连好语音服务器（这一项没在真实网络上测过，不好用会自动退回原来的方式）。

## 0.2 改了什么

- 不卡了（目标）：0.1 的宠物窗口铺满整个屏幕，系统每一帧都要合成一整屏透明层。现在宠物窗口只比宠物大一圈，跑的时候整个窗口跟着挪；按钮上的光圈、框选翻译各是一个用到时才出现的小窗口（0.3.1 起都画在宠物窗口里）。
- 呼吸模式看窗口的方式：窗口露在外面时直接拷屏幕上那一块（几乎不花时间），被挡住时才让那个程序自己画一遍，而且最多 3 秒一次（以前每 0.7 秒一次，会让 Chrome、Electron 这类程序整页重画）。
- 不用终端：一键安装、浏览器登录。
- 接入 Claude 桌面版：桌面版里的聊天能用宠物看屏幕、指按钮、帮你点和打字。
- 不会再把 Claude 桌面版误当成 Claude Code 去启动。
