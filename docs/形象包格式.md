# Claude 宠物 · 形象包格式

宠物的样子和动作都来自"形象包"：一个文件夹，里面一个 `pack.json` 加若干素材文件。动作编号和《动作设计表》一致（A01…F07）。缺哪个动作都行，程序会用替补动作或程序动画先顶上，做好一条放进来一条。

## 放在哪

- `%APPDATA%\com.claudepet.app\sprites\<包名>\`（设置页"打开形象包文件夹"直接打开这里），或者 `ClaudePet.exe` 旁边的 `sprites\<包名>\`
- 放好后：设置 → 宠物 → 形象包，选它。

## pack.json

```json
{
  "name": "叶瞬光",
  "fps": 30,
  "size": [600, 600],
  "anchor": [0.5, 0.97],
  "eye": { "x": 0.467, "y": 0.386, "rx": 0.17, "ry": 0.075 },
  "actions": {
    "A01": { "video": "A01.webm", "loop": true },
    "B02": { "video": "B02.webm", "loop": true },
    "B03": { "video": "B03.webm", "reverse": "B03_rev.webm" },
    "B04": { "video": "B04.webm" },
    "C01": { "video": "C01.webm", "hit": 21, "tip": [512, 238] },
    "C02": { "video": "C02.webm", "loop": true, "tip": [512, 238] },
    "E03": { "pattern": "E03/%04d.png", "count": 120, "loop": "pingpong" }
  }
}
```

| 字段 | 意思 |
|---|---|
| `fps` | 素材帧率，默认 30。请照实写：C01 的 `hit` 帧号要靠它换算成时间 |
| `size` | 素材原始宽高（像素）。写了它，下面的坐标就可以直接填像素 |
| `anchor` | 脚底中心在画面里的位置。宠物"站在哪儿"就是指这个点 |
| `eye` | 眼睛的椭圆范围（点眼睛 = 读屏） |
| `body` | 可选，角色实际占的范围 `[x0, y0, x1, y1]`。不写就从 A01 的透明通道自动量。宠物大小、能点到的范围、气泡位置都按它算，所以素材四周留白没关系 |
| 坐标写法 | 0–1 之间按比例算，大于 1.5 按像素算（以 `size` 或素材实际尺寸换算） |

每个动作（`actions` 里的一项）三选一：

| 写法 | 适合 |
|---|---|
| `"video": "C01.webm"` | **推荐**。WebM（VP9 + 透明通道）。占内存极少。30 帧就行，程序按视频自己的帧率播 |
| `"pattern": "C01/%04d.png", "count": 72`（可加 `"start": 1`）或 `"frames": [...]` | PNG 序列帧。方便试，但会整段解码进内存，动作多了吃内存 |
| `"src": "C01.png"` | 一张静态图（程序动画让它动）；`.webp/.gif` 动图会自己动 |

其它选项：

| 选项 | 意思 |
|---|---|
| `loop` | `true` 循环 / `false` 单次（默认按设计表）/ `"pingpong"` 正放再倒放（只对序列帧有效；视频请把来回烘进文件里） |
| `reverse` | 倒放用的另一个视频文件（B03 转身倒放 = 侧→正，E01 倒放 = 眼睛熄灭）。序列帧不用给，程序自己倒着播 |
| `hit` | C01 按下的那一帧（帧号，从 0 数）。播到这一帧程序才真的点击 |
| `tip` | 指尖位置（C01–C04、C06）。程序把宠物摆在"指尖 = 按钮"的地方：按 = 按钮中心，指 = 按钮边上 |

## 做素材的规矩（和设计表第 0 节一致）

1. 所有动作画面一样大、角色一样大（同一个 `size`，同一个脚底位置）。待机 A01 的宽高比就是宠物的宽高比。
2. 正面系列从 P正 开始、回到 P正；侧面系列从 P侧 开始、回到 P侧。程序在两者之间自动插 B03 转身。
3. 侧面动作只做朝右的，朝左程序镜像。
4. 背景透明，不画按钮、光圈、气泡、文字（Zzz 和感叹号除外）。
5. 设置里的“大小”指角色本身的高度（默认 240 像素，可调 140–400），四周留白不算。导出画面 480–600 像素高就够清楚，不用 1080。

## PNG 序列 → WebM（透明）

```
ffmpeg -framerate 30 -i C01/%04d.png -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 30 -auto-alt-ref 0 -vf scale=-2:600 C01.webm
```

倒放版本（B03、E01 需要）：

```
ffmpeg -i B03.webm -vf reverse -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 30 -auto-alt-ref 0 B03_rev.webm
```

注意：解码带透明的 WebM 时要用 libvpx-vp9 解码器，否则透明会丢。用 `ffmpeg -c:v libvpx-vp9 -i C01.webm -frames:v 1 check.png` 抽一帧看看背景是不是透明。

## 程序什么时候播哪个动作

| 时机 | 动作 |
|---|---|
| 平时 | A01 循环；每 8–20 秒随机插一条 A02–A11（A02、A03 最常见；空闲 1 分钟后才会 A04/A10；2 分钟后 A12） |
| 空闲 3 分钟 | F03 打瞌睡 → F04 睡觉；有事 F05 醒来 |
| 帮你点按钮 | B03 转身 → B02 跑 → B04 急停（和减速同步）→ C01（hit 帧真点击）→ C05 竖拇指 → 跑回原位 |
| 指给你看 | B03 → B02 → B04 → C02 循环（程序画光圈）+ 每 3 秒 C03 + 8 秒没点 C04 → 你点了 D03，取消/超时 C07 |
| 帮你打字 | 跑过去 → C01 点输入框 → C06 敲键盘循环 |
| 滚动页面 | C09 |
| 很远（> 1500 像素） | B09 消失 → B10 在目标处出现 |
| 目标在上方/下方很远（有 B06 时） | B06 跳起悬空移动 → B07 落地 |
| Claude Code 要你确认 | D01 循环（提醒气泡在的时候） |
| 在想 / 在说话 | D02 / E03 |
| 呼吸模式 | 开：E01 → E02 循环；关：E01 倒放 |
| 你那边的 Claude 答完一轮 | D03 |
| 出错 | D04（没有就 F02） |
| 点它身体 / 连戳 4 下 / 鼠标停在头上 | F01 / F07 / F06 |
| 拖它 / 松手 | B08 / B07 |
| 启动 | B11（没有就 B10） |

没有素材的动作：有替补就用替补（比如 C05↔D03、B01↔B02、D04→F02），否则用程序动画（缩放、摇摆之类），转身 B03、起跑 B05 这种直接跳过。
